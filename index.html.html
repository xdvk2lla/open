Optional 1-line script to spawn subprocesses from web calls

Standard browsers prevent arbitrary websites from silently opening arbitrary binaries like calc.exe without prompts. While this web app uses valid native URI schemes (ms-calculator: and whatsapp://), you can also run this mini Python bridge locally:

# python -c "import subprocess, http.server; ..."
